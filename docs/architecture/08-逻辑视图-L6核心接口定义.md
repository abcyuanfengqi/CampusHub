## 1. 接口清单（8个关键接口）

### 认证接口（M1）

**1. 用户登录**
```
POST /api/auth/login
Content-Type: application/json
Authorization: 无（匿名）

请求体:
{
  "username": "student",      // 必填
  "password": "123456"         // 必填
}

响应 200:
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 2,
    "username": "student",
    "nickname": "同学",
    "role": "STUDENT",
    "token": "eyJhbGciOiJIUzM4NCJ9..."  // JWT，有效期2小时
  }
}
```
*失败：密码错误 → code:500 message:"密码错误"*

**2. 用户注册**
```
POST /api/auth/register
请求体:
{
  "username": "stu2026",       // 必填 3-20字符
  "password": "123456",        // 必填 ≥6位
  "nickname": "小明",
  "email": "xm@mail.com",
  "phone": "13800138000"
}
响应 200: { code:200, data:{ id, username, nickname, role:"STUDENT", token } }
*失败：用户名已存在 → code:500 message:"用户名已存在"*
```

### 活动接口（M4）

**3. 创建活动**
```
POST /api/activity
Authorization: Bearer {token}
请求体:
{
  "title": "秋季篮球赛",         // 必填
  "description": "3v3 篮球赛...",
  "clubId": 1,                  // 可选，社团发起
  "location": "东区体育馆",
  "startTime": "2026-11-01 14:00",
  "endTime": "2026-11-01 17:00",
  "maxParticipants": 100
}
响应 200: { code:200, data:{ id, status:"DRAFT" } }
*权限：发起人角色 ≥ CLUB_LEADER*
```

**4. 活动报名（核心状态机+并发控制）**
```
POST /api/activity/{activityId}/register
Authorization: Bearer {token}
响应 200: { code:200, data:{ registrationId, status:"REGISTERED" } }

流程: 校验状态=REGISTERING → Redis原子扣减名额 → DB乐观锁回写
      → 发布 REGISTRATION_EVENT → 异步写站内消息
*失败: 名额已满(500) / 活动非报名中(500) / 重复报名(500)*
```

**5. 活动签到核销（C2 状态流转）**
```
POST /api/activity/{activityId}/checkin
Authorization: Bearer {token}
请求体: { "code": "QR二维码内容" }   // QR_CODE方式
响应 200: { code:200, data:{ checkinId, status:"CHECKED_IN" } }
*失败: 未报名(500) / 已签到(500，uk_activity_user防重复)*
```

### 社团接口（M2）

**6. 创建社团（审批流状态机）**
```
POST /api/club
Authorization: Bearer {token}
请求体:
{
  "name": "计算机协会",
  "category": "科技",
  "description": "..."
}
响应 200: { code:200, data:{ id, status:"PENDING" } }
*流程: 创建 → PENDING → 管理员审批 → APPROVED/REJECTED（审批流 C2）*
```

### 二手接口（M6）

**7. 发布二手商品**

Authorization: Bearer {token}

{
  "title": "二手教材 高数上册",
  "price": 15.00,

Authorization: Bearer {token}（角色=ADMIN）

## 2. 接口设计规范

1. **统一响应**：所有接口返回 `Result{code, message, data}`，code=200 成功，非200 为业务错误
2. **认证方式**：JWT Bearer Token（`Authorization: Bearer xxx`），2小时过期；未登录访问业务接口 → 401
3. **RESTful 风格**：资源名复数、路径层级 `/api/{模块}/{资源}/{动作}`
4. **幂等设计**：报名/签到接口利用唯一键（uk_activity_user）保证重复请求不产生副作用
5. **异步解耦**：报名成功不阻塞写通知（发布事件到 RabbitMQ，消费者异步落库）
6. **接口文档**：SpringDoc 自动生成 OpenAPI 3 文档，访问 `/api/swagger-ui.html`
