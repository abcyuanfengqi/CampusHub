# ADR-002：前端框架选型

- 日期：2026-10-27
- 状态：已接受
- 涉及视图：逻辑 / 开发 / 运行

## 背景

CampusHub 前端需要实现登录注册、9 大模块的列表/详情/表单页面、管理端数据看板（图表），要求：开发效率高（个人 14 周）、组件化复用（36 个子功能）、响应式布局（桌面为主）、与后端 REST API 顺畅对接、构建工具成熟。

约束条件：
- 必须支持 SPA + 路由（登录页/主布局/各模块页面）
- 需具备状态管理（用户登录态、消息未读数）
- 数据可视化（M8 看板需图表库）
- 本人前端基础为 Vue 方向（本科课程 + 项目骨架已用 Vue 3）

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| A. Vue 3 + Vite + Element Plus + Pinia | 中文生态友好、组合式API开发效率高、Vite秒级热更新；Element Plus组件覆盖管理后台全部需求；Pinia轻量类型安全 | 生态中大型表格/复杂交互需自研封装 |
| B. React 18 + Next.js + Ant Design | 生态最大、hooks灵活、SSR支持 | 本人无React实战经验，学习成本高；Next.js对本项目SPA场景过度；Ant Design中后台同样优秀但与Vue技术栈割裂 |
| C. uni-app（Vue语法） | 一套代码多端（小程序+H5+App） | 本项目要求Web应用+演示，小程序非必需；uni-app对复杂交互与自定义UI支持弱，调试成本高 |
| D. 原生/传统多页（JSP/Thymeleaf） | 无跨域问题、简单 | 前后端耦合、组件复用差、开发效率低，无法满足36个子功能规模 |

## 决策

**选择 A：Vue 3.4 + Vite 5 + Element Plus + Pinia + Vue Router + Axios。**

具体选型组合：
- 构建工具：Vite 5（开发服务器端口 5173，`/api` 代理到 8080）
- UI 组件库：Element Plus（登录/注册/表单/表格/弹窗全覆盖）
- 状态管理：Pinia（登录用户信息、全局消息未读数）
- 路由：Vue Router 4（登录/注册/主布局+子路由）
- HTTP：Axios 封装（baseURL `/api`、JWT 拦截器、统一错误提示）
- 图表：ECharts（M8 数据看板使用，5.x）

## 理由

1. **开发效率与团队适配**：本人 Vue 基础可直接上手；Vite 秒级热更新让页面开发迭代极快；Element Plus 组件化使 36 个子功能页面以"表单+表格+卡片"快速组装。
2. **与后端解耦**：Axios + JWT 拦截器实现前后端分离标准形态（与 ADR-001 的 REST API 对接）；开发期 Vite 代理解决跨域，生产期 Nginx 反向代理（L3 容器图已规划）。
3. **状态与路由能力**：Pinia 管理登录态（token + userInfo），Vue Router 实现登录/注册/主布局多级路由，路由守卫做未登录拦截——已在前端骨架落地。
4. **放弃的代价**：放弃 React 意味着没有 SSR/React 生态；本项目是登录后的管理型系统（SPA 完全够用），不需要 SEO/SSR，代价可接受。放弃 uni-app 意味着不覆盖小程序端——任务书要求的是 Web 应用 + 在线环境演示，小程序非评分项。
5. **数据看板**：ECharts 与 Vue 3 组合式 API 集成成熟，满足 M8 图表需求（折线/柱状/饼图）。

## 影响

- **逻辑视图**：前端容器承载登录注册、9 模块页面、管理看板；页面结构 = 登录页 + 注册页 + 主布局（侧边栏导航 9 模块 + 顶栏用户区）
- **开发视图**：`src/` 下按 `api/`（接口封装）、`views/`（页面）、`components/`（组件）、`router/`、`stores/`、`utils/`（axios封装）组织
- **运行视图**：Vite dev server 5173（开发）/ Nginx（生产）；JWT 存 localStorage，请求拦截器注入 Authorization
- **质量属性**：页面加载 ≤2s（代码分割+懒加载路由）、可维护性（组件化）
- **后续事项**：第10-12 周随后端模块同步开发对应页面；第13 周构建产物部署到 Nginx

## 验证方式

1. `npm run dev` 启动，登录页可访问（已验证 ✅）
2. 登录/注册页对接真实后端接口（已验证 ✅：admin/123456 返回 JWT 并跳转首页）
3. 9 个模块页面与后端接口联调通过（第 12 周验收）
4. 生产构建 `npm run build` 成功，Nginx 部署可访问（第 13 周验证）
5. 若出现跨域、构建性能问题，重新评估 Vite 代理与分包策略
