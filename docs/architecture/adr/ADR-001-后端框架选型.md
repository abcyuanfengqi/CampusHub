# ADR-001：后端框架选型

- 日期：2026-10-27
- 状态：已接受
- 涉及视图：逻辑 / 开发 / 运行

## 背景

CampusHub 是 9 大业务模块、3 类角色、含状态机与异步消息的中型全栈项目。后端框架需要满足：快速开发（14 周个人完成 9 个模块）、支持事务与复杂查询（报名名额递减、社团审核流）、易集成缓存与消息队列（C2/C3 复杂度要求）、单机可部署、社区成熟度高。

约束条件：
- 开发语言限定在 Java 生态（本人本科软件工程背景，Java 基础扎实，Python 无经验）
- 必须满足任务书 C2（状态流转/审批流）与 C3（异步消息）复杂度要求
- 个人开发，要求脚手架友好、开发效率优先

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| A. Spring Boot 3 + MyBatis-Plus | 生态成熟、约定优于配置、自动装配、内嵌Tomcat、微服务可演进；MyBatis-Plus 提供 CRUD/分页/乐观锁开箱即用 | 相比 Node/Python 启动稍重；新手需理解自动配置原理 |
| B. Spring Cloud 微服务全家桶 | 分布式能力完备（注册中心/网关/熔断） | 对本项目严重过度设计：单机即可承载，9个模块按微服务拆分运维成本高、开发量翻倍 |
| C. SSM（Spring + SpringMVC + MyBatis） | 轻量、经典 | 配置繁琐（XML/注解混编）、无自动配置、开发效率低，14周个人完成9模块不现实 |
| D. Node.js（Express/NestJS） | 轻量、前后端同语言 | 本人 Java 背景无 Node 后端经验；事务/类型安全弱于 Java；团队无可复用经验 |

## 决策

**选择 A：Spring Boot 3.2 + MyBatis-Plus 3.5.5，Java 17。**

具体选型组合：
- Web 框架：Spring Boot 3.2.5（spring-boot-starter-web）
- 持久层：MyBatis-Plus 3.5.5（mybatis-plus-spring-boot3-starter）
- 安全认证：Spring Security + JWT 0.12.6（jjwt）
- 参数校验：spring-boot-starter-validation
- 接口文档：springdoc-openapi 2.3.0（Swagger UI）
- 缓存：Spring Data Redis（Lettuce）
- 消息：spring-boot-starter-amqp（RabbitMQ）

## 理由

1. **开发效率**：Spring Boot 自动装配省去大量配置，MyBatis-Plus 使单表 CRUD 无需手写 SQL，9 个模块 14 周可完成；个人开发不选微服务（方案B），避免分布式复杂度。
2. **满足复杂度要求**：Spring Security + JWT 支撑 C1 多角色权限；MyBatis-Plus 乐观锁 + 枚举状态机支撑 C2 状态流转；AMQP 集成 RabbitMQ 支撑 C3 异步消息。
3. **工程成熟度**：Spring Boot 3 是当前 Java 主流，招聘市场需求大；社区文档、AI 训练语料充足，配合 AI 辅助开发效率高。
4. **放弃的代价**：放弃方案 B 意味着将来无法水平扩展——本项目定位为校园级（千级用户、峰值 QPS 100），单实例 + 中间件完全够用，若未来扩容可平滑演进到微服务（模块分包已按域划分）。
5. **与 Vue 前端的协作**：REST + JSON 是前后端分离的标准形态，与 ADR-002 选定的前端架构天然契合。

## 影响

- **逻辑视图**：9 个模块在后端按 `modules/` 分包（user/club/competition/activity/notice/secondhand/lost/data/file），与 L2 功能树一一对应
- **开发视图**：源码目录、依赖清单、编码规范均以此为准；pom.xml 已固定版本
- **运行视图**：单 Web 进程 + MySQL + Redis + RabbitMQ，端口 8080
- **质量属性**：可维护性（模块化）、可测试性（JUnit + MockMvc，后续补 ≥10 单测）、性能（缓存 + 索引满足 ≤500ms）
- **后续事项**：第10-12 周按模块批量实现；第13 周 Docker 化部署

## 验证方式

1. 启动后端（mvn spring-boot:run）→ 登录接口实测返回 200 + JWT（已验证 ✅）
2. Swagger UI 可访问（http://localhost:8080/api/swagger-ui.html）✅
3. 9 个模块接口全部可测（第 12 周验收）
4. 单测累计 ≥10 个通过（mvn test 退出码 0）
5. 若某模块需要分布式能力（如跨模块事务、分布式锁），重新评估 ADR-005 部署形态
