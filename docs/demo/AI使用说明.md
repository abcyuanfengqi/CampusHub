# AI 使用说明

本项目在开发过程中使用 AI 工具（豆包）辅助完成需求分析、架构设计、编码实现与文档撰写。以下说明 AI 的使用方式与协作过程，符合课程对 AI 使用透明化的要求。

## 一、AI 使用范围

| 阶段 | AI 用途 | 人类角色 |
|---|---|---|
| 需求分析 | 梳理 9 大功能模块、角色定义、状态机设计 | 确认业务方向（大学生服务中心） |
| 架构设计 | 五视图文档框架、ADR 决策记录撰写、架构图绘制脚本 | 评审与选择备选方案 |
| 编码实现 | 后端 9 模块代码生成、前端 11 页面、单元测试编写 | 审核代码、运行验证、修复问题 |
| 文档 | 架构设计说明书、提交清单、PPT 大纲 | 审核数据准确性 |
| 环境 | 安装配置 JDK/Maven/MySQL/Redis/RabbitMQ/Node | 授权安装、提供凭据 |

## 二、使用记录

1. **环境搭建**（2026-10-21）：AI 指导并协助安装 JDK17、Maven、MySQL、Redis、RabbitMQ、Node.js、VS Code、IDEA，配置环境变量与 GitHub SSH。
2. **需求与选题**（2026-09-21）：AI 评估"大学生服务中心"选题可行性，对比实验室项目方向，输出 9 模块方案与 CampusHub 命名。
3. **数据库设计**（2026-09-21）：AI 生成 19 张表建表 SQL 与 ER 图（PIL 绘制）。
4. **架构文档**（2026-10-27）：AI 按任务书附录 B 模板生成 8 条 ADR 与五视图 12 份文档、11 张图。
5. **编码实现**（2026-10-28）：AI 生成后端 9 模块与前端全部页面，使用自研 3 个 Skill（campus-project-scaffold / module-generator / arch-doc-sync）加速开发，使用日志见 docs/skills/usage-log.md（6 次）。
6. **测试与修复**（2026-10-28）：AI 编写 17 个单元测试，定位并修复 LambdaUpdateWrapper 缓存、Jackson 时间格式、前端看板字段不匹配等 5 个问题。

## 三、AI 生成内容的核验方式

- 后端：`mvn compile` + `mvn test`（17 用例全通过）验证
- 前端：`npm run build` 验证 + 浏览器实际访问截图
- 数据：通过 API 注入演示数据并查库验证中文存储正确性
- 架构文档：与代码实现逐项对照（追溯矩阵 15 条）

## 四、声明

AI 生成代码均经过人工阅读、运行验证与问题修复后合入；核心架构决策（技术选型、模块划分、并发与异步方案）由本人确认。
